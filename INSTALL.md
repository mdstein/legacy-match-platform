# Installing and running from source

This project is archived and unmaintained. The steps below are how it was built and
run during development. Some files are not included (see step 1), so expect to adapt.

## Requirements

- Windows 10/11 (the game client, launcher, native adapter and game server are
  Windows-only; the API and web app also run on Linux).
- Node.js 22 or newer with npm.
- Docker (PostgreSQL, Redis and S3-compatible storage for the local stack).
- Rust (stable) and the Tauri prerequisites (WebView2) for the launcher.
- For the native adapter in `vendor/csgo-gc`: Visual Studio 2022 or newer with the
  x86 C++ toolset, CMake, Ninja and vcpkg.
- A Steam account that owns the game, to install the client and dedicated server yourself.

## 1. Restore files that are not in this repository

- Steamworks SDK headers, older interface declarations and game-coordinator message
  definitions: see `vendor/csgo-gc/THIRD_PARTY.md`.
- Valve artwork was removed: item images (`apps/web/public/trading-items/`), rank icons
  (`apps/web/public/ranks/1.svg`–`18.svg`) and the packed launcher rank images
  (`apps/launcher/assets/packed/rank-*.bgra`, generated by `node scripts/build-launcher-art.mjs`
  from the rank icons). Without them the UI shows empty images and the launcher test
  target does not compile. Do not redistribute Valve artwork.

## 2. Backend: API, web app and database

```powershell
npm install
npm run infra:up      # PostgreSQL, Redis and MinIO in Docker
npm run dev           # API and web app
npm test              # unit tests; integration tests need the local stack
```

Configuration variables are listed in `.env.example`; see `docs/development-notes.md`.

## 3. Launcher

```powershell
npm run launcher:build        # apps/launcher/target/release/b2g-launcher.exe
```

See `docs/launcher.md` and `docs/launcher-setup-recovery.md`.

## 4. Native client adapter (csgo_gc fork)

From an x86 Visual Studio Developer PowerShell or Command Prompt:

```powershell
cmake -S vendor/csgo-gc -B vendor/csgo-gc/build -G Ninja -DCMAKE_BUILD_TYPE=Release `
  -DCMAKE_TOOLCHAIN_FILE="$env:USERPROFILE\vcpkg\scripts\buildsystems\vcpkg.cmake" `
  -DVCPKG_TARGET_TRIPLET=x86-windows-static
cmake --build vendor/csgo-gc/build
```

## 5. Game server (optional)

The dedicated server, SourceMod plugin and node agent are described in
`docs/deployment.md`. `npm run game:node:release` packages the node agent;
`deploy/hosts/windows/Install-AftertickGameNode.ps1` installs it.
